# Lusso Parfum

Panel privado y catálogo público para Lusso Parfum.

## Desarrollo local

```bash
npm install
npm run dev
```

Configura en Vercel las variables `VITE_SUPABASE_URL` y `VITE_SUPABASE_ANON_KEY`. No subas un archivo `.env` ni claves privadas.

## Producción

```bash
npm run build
npm run preview
```
